# Sistema MD: inicio en otra PC

Esta es una copia limpia del programa: no incluye entornos preparados, biblioteca ni cuentas.

1. Extrae todo el ZIP en una carpeta nueva.
2. Sigue [GUIA_PRUEBA_OTRA_PC.md](GUIA_PRUEBA_OTRA_PC.md): Python 3.12 x64/Tk, verificación del manifiesto y preparación explícita del núcleo.
3. Prepara MarkItDown con el script de la guía si deseas usar ese motor. No viene instalado.
4. Ejecuta el control sintético antes de abrir documentos personales.
5. Abre **SISTEMA_MD.bat**; API/CLI y TypeSafe requieren su configuración propia en este equipo.

La guía detalla rutas, conexiones, pruebas, migración, errores y limitaciones. No es un instalador comercial autónomo; requiere Internet durante la preparación inicial.
