# Sistema MD: paquete de prueba en otra PC

1. Extrae TODO el ZIP a una carpeta local donde puedas escribir. No ejecutes desde la vista comprimida.
2. Abre **GUIA_PRUEBA_OTRA_PC.md**. Incluye instalación, comprobación, rutas, conexiones, migración, errores y checklist.
3. Prepara Python y dependencias en esa PC siguiendo la guía. Después abre **SISTEMA_MD.bat**.
4. Ejecuta **PROBAR_EQUIPO.py** con los comandos de la guía y conserva el informe.

Este paquete contiene el código, pruebas, preparadores y documentación. No contiene claves, sesiones, biblioteca personal, Python, entornos virtuales, clientes CLI ni modelos pesados. La instalación inicial necesita Internet. No es todavía un instalador comercial autónomo.

MarkItDown se prepara con el script incluido. Docling tiene adaptador pero todavía requiere preparación y control real; Marker/MinerU permanecen pendientes. No se envía nada a una IA por abrir el programa.

**No hay ninguna orden de apagar la PC dentro de este ZIP.** El apagado solicitado corresponde solo al equipo de origen tras guardar esta entrega.
